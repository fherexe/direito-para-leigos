📘 Direito CLT — Blog Informativo sobre Direitos Trabalhistas

Direito CLT é um projeto de blog estático desenvolvido com foco em conteúdo informativo, acessível e bem estruturado sobre direitos trabalhistas no Brasil, baseado na Consolidação das Leis do Trabalho (CLT).

O projeto foi criado para praticar desenvolvimento Front-end, organização de páginas, reutilização de componentes e construção de interfaces claras para leitura e navegação.

🔗 Demo:
https://fherexe.github.io/direito-clt/

🎯 Objetivo do Projeto

Criar um blog simples, rápido e acessível

Transformar conteúdos jurídicos em textos claros e objetivos

Praticar estruturação de páginas e componentes reutilizáveis

Aplicar boas práticas de HTML semântico e CSS organizado

🛠️ Tecnologias Utilizadas

HTML5 (estrutura semântica)

CSS3 (layout, responsividade e organização visual)

JavaScript (interações e comportamentos básicos)

GitHub Pages (deploy)

📂 Funcionalidades

Páginas informativas sobre direitos trabalhistas

Navegação simples e intuitiva

Layout focado em legibilidade

Estrutura preparada para expansão de conteúdo

Componentes reutilizáveis (header/footer)

🧠 Aprendizados

Durante o desenvolvimento deste projeto, foram trabalhados:

Organização de projetos Front-end

Separação de estrutura, estilo e comportamento

Criação de layouts responsivos

Pensamento em experiência do usuário (UX)

Manutenção e escalabilidade de conteúdo estático


Possível migração para um framework Front-end
